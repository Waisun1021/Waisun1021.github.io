# 一起搭獨立網站

正式網址：https://waisun1021.github.io/

2026-10-03 更新：首頁直接由 GitHub Pages 提供 HTML/CSS/JavaScript，不使用 iframe。三種共乘模式、公式、繁中英文、深淺色、手動距離和分享功能均在同一頁執行。

所有地點必須按「Google 搜尋」選取，地址欄位唯讀。未選完不能計算；手動距離也須先完成選址。每個地點旁的按鈕呼叫既有 Google Apps Script v6 Maps Geocoder，讓使用者選擇地址並核對位置；這不是逐字即時 Places 自動完成。沒有新增 API 金鑰或計費服務。地址服務可能僅回傳一筆或近似結果。

所有行程依使用者用箭頭確認的停靠順序計算，不依遠近排序、不宣稱最短路線。第一個上車的人是建議叫車者；共同上車時任一乘客都可叫車。分帳結果保留乘客身份。網站不實際叫車。

自動查詢送出所選地址與座標（locations）、模式、語言和 ordered 標記，以數值座標查開車路線，避免地址重新解析。地址搜尋只送搜尋文字及語言。姓名和車資只在瀏覽器處理，不保存行程。手動距離仍在本機計算，但按地址搜尋仍會送出該地點。JSONP callback 限制、逾時與過期回應防護保留。

Google Apps Script 來源保留在私人 taxi-split-web 儲存庫。AdSense 程式碼與 ads.txt 已設定並送審，放送須經 Google 核准。

## 穩定性

locations.js 管理選址資料，核對顯示地址及座標範圍。只在當頁記憶體存放，刷新需重新選址。未選完顯示進度並停用計算按鈕，送出時再次驗證。移除乘客清除其選址，切換模式只驗證目前需要的地點。重新搜尋取消時保留已選地點，不提交未選文字。搜尋重複送出會阻擋，取消或修改查詢時清理 script/計時器並忽略過期回應。Google 失敗或額度用完會顯示錯誤，不允許手打地址繞過選址。

執行 `node locations.test.cjs` 驗證三種模式、必填地點、地址改變、乘客移除與無效座標。Google 回傳結果仍可能近似，必須核對實際入口；此設計無法保證 Google 永遠可用或位置百分之百正確。
