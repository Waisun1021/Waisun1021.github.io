隱私說明Privacy notice

更新日期：2026 年 10 月 3 日。以下說明目前網站的實際資料處理方式。Updated October 3, 2026. This notice describes the site’s current data handling.

計算資料與 Google 地圖Calculator data and Google Maps

姓名、總車資與分帳結果在你的瀏覽器中處理，本站不將它們寫入資料庫。按「Google 搜尋」時，該次搜尋的文字與語言會傳送至本站的 Google Apps Script 服務，再由 Google Maps 搜尋地址。使用自動距離時，你確認順序的上下車地點、行程模式與語言也會傳送到該服務查詢開車路線。本站程式不儲存搜尋結果或行程。Names, fares and allocations are processed in your browser and are not written to a site database. Pressing Google search sends that search’s text and language to the site’s Google Apps Script service for Google Maps address results. Automatic distance requests also send your ordered stops, trip mode and language to that service for driving routes. The site code does not store search results or trips.

手動模式不會為距離計算傳送地點；但若按「Google 搜尋」或開啟 Google 地圖連結，該次搜尋的地點仍會傳送給 Google。計算介面由 GitHub Pages 提供。自動查詢會把地點放入傳給 Google 的查詢請求，Google 可能處理請求與服務所需的技術資料。本站沒有要求 GPS、相機、麥克風、Gmail、聯絡人或 Google Drive 存取。Manual distance calculations do not send stops to the map service. Using Google address search or opening a Google Maps link still sends that search’s place to Google. GitHub Pages serves the calculator directly. Automatic queries include stops in requests to Google, which may process technical information needed to deliver its services. The site does not request GPS, camera, microphone, Gmail, contacts or Drive access.

偏好設定與網站託管Preferences and hosting

網站及計算工具會嘗試使用瀏覽器本機儲存記住語言與外觀偏好；你可以清除網站資料移除設定。偏好儲存失敗不影響基本計算。The website and calculator try to store language and appearance preferences locally in your browser. Clear site data to remove them. Basic calculations remain available if preference storage fails.

網站與計算介面由 GitHub Pages 託管，地址搜尋與地圖距離查詢使用 Google Apps Script。服務供應商可能接收 IP 位址、瀏覽器資訊及一般請求記錄；例如 GitHub 說明其會記錄訪客 IP 位址作安全用途。GitHub Pages hosts the website and calculator interface; address searches and map distance queries use Google Apps Script. Providers may receive IP addresses, browser information and request logs. GitHub states that it logs visitor IP addresses for security purposes.
